
# Tools Used – Network and Web Reconnaissance

## 1. Kali Linux
A Linux-based operating system used as the testing environment for performing reconnaissance activities.

## 2. Wappalyzer
Used to identify technologies and frameworks associated with a website.

## 3. Netcraft
Used to gather publicly available information about website infrastructure and hosting.

## 4. GoBuster
Used for directory and file enumeration on the authorized lab web application.

## 5. Subfinder
Used to discover subdomains associated with a target domain.

## 6. DNSX
Used to perform DNS resolution checks on discovered subdomains.

## Conclusion
These tools helped perform different stages of the reconnaissance process, from network information gathering to subdomain discovery and DNS resolution.
